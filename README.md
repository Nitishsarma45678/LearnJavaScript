## Features

- Basics of JavaScript

- Practice exercises

## 🛠 Getting Started

To get a local copy of the repository up and running, follow these simple steps:

### Prerequisites

Make sure you have the following installed:

- Git
- Node.js (optional, for running JavaScript outside the browser)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Nitishsarma45678/LearnJavaScript.git
   ```

Usage:

Explore the repository's contents to start learning:

Open index.html files in your browser to see examples in action.
Modify JavaScript files (.js) and experiment with the code.
Run the code in your browser's console or a Node.js environment for practice.
